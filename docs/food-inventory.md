# 음식·음료 원본 수집 범위

2026-09-12에 `D:/SPT`의 실제 아이템 데이터, `Windows.json`과 번들을 대조했다.
섭취 가능한 아이템 42개 레코드에는 같은 보드카 모델을 쓰는 중복 레코드가 있어 고유 품목은 41개다.
각 아이템의 `Prefab`(바닥 모델)과 `UsePrefab`(사용 동작)을 모두 출발점으로 삼아 의존성을 추적했다.
음식·사용 아이템 관련 번들 160개에서 기존에 추출하지 않은 Texture2D 19개를 확인했다.
식품 계열 교환용 물품 네 품목의 12개도 수집 범위에 추가했다.

총 9개 번들, 11개 텍스처 대상, 31개 원본 맵을 추가했다. 커피·홍차·소금은
게임에서 섭취 가능한 음식·음료가 아니므로 프로필의 `category`를 `barter`로 구분한다.
`vodka-use`와 `sprats-fishpiece`의 실제 재질에는 D/N만 연결되어 있어 G를 생성하지 않는다.
사용 동작용 라벨의 14개 맵과 교환용 물품의 12개 맵은 편집 준비 대상이며,
내용물의 5개 맵은 글자가 없어 보존한다.

마요네즈·보드카·댄 재키엘·스프랫은 기존 바닥 모델과 사용 동작용 원본이 서로 다르다.
같은 품목의 브랜드와 번역 문구는 맞추되, 한 모델의 편집 이미지를 다른 UV에 복사하거나
전체 리사이즈로 대체하지 않는다. 특히 기존 마요네즈 적용만으로 사용 동작까지 완료된 것은 아니다.
프로필의 `exact_text`는 제안이며, 본격 편집 전에 각 원본을 판독해 확정한다.

## 현재 목록과 로컬 파일

[collection.json](../profiles/food/collection.json)은 텍스처를 포함한 번들 50개와 텍스처 대상 53개를 등록한다.
대상은 한글화 48개, 보존 5개이며 이는 품목 수나 한글화 완료 수와 다르다.
보존 대상은 `moonshine`, `purewater`, `snacks-generic`, `sprats-fishpiece`, `galette-cracker`다.

수집 결과는 Git에서 제외하는 `workspace/test-textures/`에 있다.

- `<id>/original/`: 원래 이름·해상도·RGBA 픽셀을 유지한 작업용 원본 157장.
- `목록.csv`, `manifest.json`: D 53장, N 53장, G 51장의 경로·크기·해시·공유 여부.
- `_inventory-20260912/`: 최신 전체 추출과 Material/Renderer 연결 증거. 내용물 등을 포함한 Texture2D 177개.
- `_inventory/`: 이전 추출 기록.
- `추가-추출-검증.json`: 추가 파일과 기존 원본·편집 파일 보존 검사.
- `편집-준비-검증.json`: 새 한글화 대상 9개의 작업 폴더와 초기 후보 검사 결과.

작업용 원본 157장에는 랫콜라·타르콜라가 공유하는 N/G의 중복 사본 2장이 포함되어
고유 Texture2D는 155개다. 전체 추출 177개 중 나머지 22개는 기존의 숟가락·음식 내용물·추가 LOD 등이다.
이들은 전체 추출에 보관하며 새 한글화 대상으로 자동 지정하지 않는다.

추가한 한글화 대상의 편집 폴더는 `workspace/items/<id>/`에 있다.
`job.json`과 `EDITING.md`를 확인하고 `maps/*/candidate.png`를 편집한다.
내용물 보존 대상은 원본 수집 목록에만 두고 편집 폴더를 만들지 않는다.
추출 및 초기 후보 검증은 한글화 완료나 게임 외형 확인을 뜻하지 않는다.

## 다음 자산 조사 기준

현재 프로필의 텍스처 번들만 다시 읽어서는 사용 동작의 별도 자산을 발견할 수 없다.
아이템 데이터의 `Prefab`과 `UsePrefab`에서 각각 의존성을 끝까지 추적한 뒤,
실제 Texture2D·Material/PPtr·Renderer/Mesh와 수집 목록을 비교한다.
확장자가 없는 카탈로그 키도 추적하고 파일명만 같다고 중복으로 판단하지 않는다.

구형 소시지 `item_food_sausage_saltydog/item_food_kolbasa.bundle`과 구형 문샤인
`bottles_with_alcohol/item_food_moonshine.bundle`은 현재 아이템의 두 모델 경로에서 참조가
확인되지 않아 한글화 목록에 추가하지 않았다. 모드가 실행 중에 생성하는 아이템은 이번 정적 조사 범위에 포함되지 않는다.
