# 번역 규칙

- 소비자가 실제 한국 포장에서 읽을 법한 짧고 자연스러운 표현을 사용한다.
- 각 영역마다 원문, 문맥상 뜻, 최종 한국어를 분리해 기록한다.
- 별도 요청이 없으면 정상 게임 화면에서 식별되는 제품명·브랜드·짧은 핵심 문구만 번역한다.
- 작은 원재료·법정표시·제조사·주소·영양·인증·바코드·날짜·장식성 미세 인쇄는 원본 그대로
  보호한다. 사용자가 전체 라벨 번역을 명시한 경우에만 이 항목들을 번역한다.
- 게임 텍스처에 인쇄된 문구가 정본이다. 실물 상품이나 회사 정보로 게임 문구를 교정하지 않는다.
- 브랜드가 의미를 전달하지 않는 고유명사면 한글로 음역한다.
- 편집 허용 목록에 포함된 식품 종류, 맛, 조리법, 경고와 개봉 지시의 의미는 번역한다.
- 작은 공간에서는 핵심 의미를 보존해 줄이되 새로운 효능이나 사실을 만들지 않는다.
- 원문의 숫자, 중량, 우편번호, 식단 번호, 화살표와 ™·®는 명세에 따라 보존한다.
- 한국어 문구 길이를 원문 글자 수에 억지로 맞추지 않는다. 자연스러운 띄어쓰기와 자간을
  우선하고, 남는 공간은 여백으로 둔다.
- 원문이 정방향이 아니면 90° 배수 여부와 관계없이 한국어를 정상 가로 방향에서 생성·검사한
  뒤 기록한 원문 각도와 진행 방향으로 단어 전체를 되돌린다. 한글 음절을 한 글자씩 세로로
  쌓거나 각도를 90° 배수로 반올림하지 않는다.
- 번역문이 짧아져도 원문의 글자 높이, 기준선, 정렬과 시각적 위계를 유지한다.
- 앞면·옆면·뚜껑처럼 면이 다른 반복 문구는 각각의 위치·회전·그림 방향을 기록한다.
- 군용 문구는 한국 군납 포장처럼 간결하게 번역하되 원문의 법적 의미를 바꾸지 않는다.
- 러시아어 제품 종류는 한국어 통용명으로 번역하고 브랜드만 음역한다.
- profile의 `exact_text`에 확정된 문구를 글자 그대로 사용하고 유의어로 바꾸지 않는다.
- OCR과 시각 판독이 일치하지 않거나 원문이 읽히지 않으면 추측하지 말고 작업을 중단한다.
- 생성 후 최종 한글의 뜻, 횟수, 방향과 배치가 번역 명세와 같은지 다시 확인한다.
