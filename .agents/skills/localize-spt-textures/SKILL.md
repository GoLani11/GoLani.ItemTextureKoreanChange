# SPT 텍스처 한글화

## 요청한 단계 선택

이 스킬이 들어 있는 저장소의 `localize.py`와 `profiles/food/collection.json`을 사용한다.
경로는 저장소 루트 기준이며, 현재 작업 위치가 다르면 루트를 먼저 찾는다.
개인 경로, 육포의 2048 해상도, 글자 좌표나 효과 강도를 다른 품목에 고정하지 않는다.

- 품목 한글화 또는 이미지 생성 요청: 원본 D를 보고 한글 D 시안을 생성해 보여주는 단계까지 진행한다.
- "이대로 원본 크기로", "이 시안으로": 선택한 D에 `adopt-draft`를 적용한다.
- "나머지도", "N/G까지": 선택한 D가 원본 크기인지 확인한 뒤 보조맵을 처리한다.
- "패키지로": 파일 검증과 테스트 패키징을 진행한다.
- 한 번에 더 넓은 범위를 요청했거나 이미 시안을 선택했다면 승인된 단계를 다시 묻지 않는다.
- 설치는 설치 요청이 있을 때 진행한다. 스킬 호출만으로 설치나 외부 배포를 추가하지 않는다.

## 원본과 문구 확인

1. `list`로 대상 ID를 확인한다. 여러 후보가 있으면 이름·모델 용도를 확인하고 요청받은 대상만 선택한다.
2. 기존 작업의 원본 해시와 재질 연결을 확인하거나 `prepare <id> --spt-root <게임 경로> --output <새 작업 폴더>`로 준비한다. 모든 자산은 `workspace/`에서 관리한다.
3. D를 `view_image`로 직접 본다. N/G 역할은 `source.json`의 실제 Material 연결을 사용하며 접미사만으로 추정하지 않는다.
4. 바닥 모델·사용 동작·LOD는 별도 원본일 수 있다. 다른 UV에 한 편집본을 복사하거나 리사이즈해 대체하지 않는다.
5. 브랜드·제품명·설명·성분표 등 판독 가능한 문구를 빠짐없이 번역한다. 숫자·단위의 의미·기호·바코드·그림을 보존하고, 판독 불가능한 글자는 지어내지 말고 원문 유지 항목으로 기록한다.
6. 사용자가 지정한 품목별 예외와 확정 문구를 우선한다. 프로필의 `exact_text`는 제안이므로 원본과 대조한 뒤 작업의 `job.json`에 문구를 기록한다. 평범한 번역 판단마다 확인을 요구하지 않는다.

## 전체 D 시안 생성과 선택

시안을 생성할 때 [프롬프트 작성 예시](references/prompting.md)를 읽는다.
내장 이미지 생성 도구에 원본 D 전체를 편집 대상으로 제공한다. 평평한 UV 텍스처임을 명시하고,
문구별 위치·정확한 한글·글자 스타일·보존할 요소를 지정한다. N/G는 이 호출에서 만들지 않는다.
내장 도구가 없거나 실패했다고 별도 유료 API로 자동 전환하지 않는다.

출력 이미지와 최종 프롬프트를 작업 폴더의 `drafts/`에 보관한다. 도구의 기본 출력 위치에만 남기지 않는다.
실제 크기·색상 모드·한글 오탈자·원문 잔상·포장 배치와 작은 글자 누락을 확인하고 이미지를 보여준다.
일반 한글화 요청에서는 이 시점에 시안과 확인이 필요한 내용을 전달한다. 자동으로 N/G나 설치까지 진행하지 않는다.

선택된 시안은 다음 명령으로 채택한다. Windows 가상환경에서는 `.venv/Scripts/python.exe`를 사용한다.

```text
python localize.py adopt-draft <job.json> <선택한-PNG>
```

이 명령은 같은 종횡비의 시안을 원본 크기로 맞추고 원본 D 알파를 복원한다.
`generated-full` 정책과 입력·출력 해시를 기록하며 N/G는 변경하지 않는다.
종횡비가 다른 시안을 억지로 늘이지 않는다. 원본 배치에 맞는 시안을 다시 선택하거나 생성한다.
해상도 보정은 새 디테일을 생성한 것으로 설명하지 않는다.

전체 D의 비문자 RGB 변화는 허용되지만 UV 배치를 바꾸거나 원본 픽셀 보존을 주장하지 않는다.
기존 `masked` 검사를 통과시키려고 전체 흰색 마스크나 가짜 `compose` 기록을 만들지 않는다.
사용자가 비문자 픽셀 보존을 요구한 작업에는 [기존 문자 합성 절차](../../../docs/editing.md)를 사용한다.

## N/G와 패키지 후속 작업

해당 단계가 요청되면 [보조맵·검증·패키징](references/materials-and-packaging.md)을 읽는다.
원본에 글자 효과가 없는 맵은 바이트 그대로 보존한다. 존재하지 않는 맵을 생성하지 않는다.
필요한 효과는 선택된 D의 동일한 글자 윤곽을 기준으로 만들고, 공유 맵과 다른 UV의 연결을 먼저 확인한다.

파일 검증, 시각 확인, 게임 확인을 구분한다. D/N/G 파일명·경로와 남은 작업을 전달하며,
테스트 패키지를 만들었다고 한글화 품질이나 게임 확인까지 완료된 것으로 기록하지 않는다.
